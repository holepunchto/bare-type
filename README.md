# bare-type

Cross-realm type predicates for Bare.

```
npm i bare-type
```

## Usage

```js
const type = require('bare-type')

if (type(123).isNumber()) {
  console.log(123, 'is a number')
}
```

## API

See the [`bare-type` reference](https://docs.pears.com/reference/bare/modules/bare-type).
